# Fishing Simulator v13.2.02

See [`docs/CHANGELOG_V13_2_02.md`](CHANGELOG_V13_2_02.md) for the release notes.

The headline feature is the clickable fleet radio UI, available from the **RADIO** HUD button next to **ANCHOR** or by pressing **Ctrl+F11**. Select a ship, ask a question, and advance the conversation line by line.
